## 核心流程與所有權

- Project → Plan → Task → Report。一個 Project 可有多個 SKU/Plan。
- Repository 存放標準 Test Case，一個 case 一個獨立 .py。匯入時間戳就是來源版本；同一時鐘刻度碰撞時遞增微秒，確保版本唯一。
- 加入 Plan 時複製 .py 與預設參數，Plan 各自獨立。Plan 適配不變更來源版本。
- 只有 Plan 編輯測項參數/.py；Task 只選執行範圍並執行，始終使用最新 Plan 定義。變更條件後保留既有結果並提示需重測。
- 執行中的 .py 不可編輯；Plan 結構與 scope 遵守執行鎖。
- 連線設定屬於 Task.environment_config，不是全域設定；不同 Task 各自維護 BMC/Console/DUT 環境。
- 舊 step/積木編輯與執行完整退役，保留歷史資料，勿恢復入口。
- Task management 已有任務列表、日期甘特圖與新增/修改/刪除；計畫日期不是自動執行排程。
- Test Plan 文件、報告格式與 Final Report 合併仍待討論。

## 目錄、拖曳、整包加入與刪除

- 測項可拖到目錄歸類。目錄拖到另一列上／下緣為排序，中央為搬入；拒絕自己/後代目錄等循環。
- 批次操作按鈕使目錄與 case 出現核取方框；BMC 方框停用。已選取項目可以一起拖曳到目錄或批次刪除。
- 同時選取父子目錄或其內 case 時，後端去除重複處理。搬移同名衝突會回滾整批。
- **最新刪除語意：刪除 Repository 目錄會一併刪除全部子目錄與標準測項。** 先前「移回上層」規則已被使用者取代，勿沿用。
- 所有 UI 刪除必須提醒與確認。確認刪除按鈕在左、取消在右。取消不得改動資料。
- Repository 刪除不影響已複製的 Plan .py、參數、Task scope 或結果。
- Plan 的 Add from Repository 也是目錄/測項列表；可從目錄列整包加入，保留所選目錄及整個子樹（含空目錄）。
- 同名 Plan 目錄沿用；既有同名測項略過，不覆蓋設定。Repository 同名多版本以最新優先。提示加入/略過數量。
- Plan 多層路徑、循環/所有權驗證、影響範圍與遞迴刪除已一併更新，批次複製失敗回滾資料庫與新寫入的檔案。

## .py 自動化宣告

TEST_CASE 的 automation 可為 automatic 或 semi_automatic；省略則顯示 Unclassified。宣告不支援的值會被拒絕。metadata 用 AST literal 解析，不執行或分析測試行為，分類不限制執行。Plan 不允許直接切換分類；需匯入新的 Repository 來源版本。

## 主要程式與 API

- web_ui/static/workbench.js：主介面、樹狀表格、inline rename、收折、拖曳、批次選取、確認視窗。
- web_ui/static/workbench.css：樣式，後方有多次已交付調整的覆寫；修改前注意 selector 優先權。
- web_ui/static/index.html：頂端入口、語言按鈕、確認對話框。
- web_ui/static/zh.js：中文詞彙/動態訊息翻譯、WeakMap 保留原始英文及屬性、MutationObserver 套用新畫面、偏好保存。不是完整的產品文案/i18n 盤點；新文案需補入翻譯。程式碼/log 不翻譯。
- web_ui/static/task_management_ui.js：任務管理與甘特圖。
- web_ui/single_case.py：metadata、Repository API、Plan 副本與 .py 定義。
- web_ui/repository_tree.py：BMC root、目錄樹/排序/刪除/批次，保護循環與衝突。
- web_ui/plan_state.py：交易、執行鎖、多層 Plan 目錄、scope/結果。reserve_plan_write 必須區分 Repository 與 Plan folder_id。
- web_ui/models.py：RepositoryFolder、RepositoryFolderCase、RepositoryFolderNode。拓樸為新增資料表；保留舊 folder identities。舊 normalized_name 的全域唯一欄位保留，新目錄用 opaque ID，名稱唯一由同層交易驗證。
- GET/POST /api/repository/folders；PATCH/DELETE /api/repository/folders/<id>。
- PUT /api/repository/testcases/<id>/folder；POST /api/repository/batch（action=move/delete、folder_ids、case_ids，move 帶 folder_id，delete 帶 confirm:true）。
- POST /api/plans/<plan_id>/repository/folders/<folder_id>：整包加入。
- 根目錄/舊資料夾採納在 Repository API 的 ensure 流程進行，具冪等性；GET 也可能完成此初始化。
