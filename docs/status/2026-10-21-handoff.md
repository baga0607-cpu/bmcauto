## Project creation and import
- New Project first asks Automatic creation vs Manual creation.
- Automatic: XLSX upload required, parse preview, then create. No name input; backend derives name from requirements sheet. Navigation uses returned Project ID. Duplicate names produce an error, never overwrite.
- Manual: name input only; creates project then opens its information in edit mode. Add SKU to fill specification template.
- Supported workbook: reference product requirements columns Category / Item / Guidance / Target Specification / Remarks, optional SKU 比較 or SKU comparison sheet. SKU values come from that matrix, not inferred from aggregate target prose. Duplicate item labels match by occurrence.

- Preview POST /api/projects/import/preview does not write. POST /api/projects/import creates project + information atomically. GET/PUT /api/projects/<id>/information uses optimistic revision checks.
